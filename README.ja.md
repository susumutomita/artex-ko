# ARTEX 韓国語版：日本語ドキュメント

## 起動と設定の概要

PostgreSQL 接続と LLM 設定が必要です。従来の Docker Compose 手順は `autumn27/artex` を参照します。既存 README は、2026-10-09 にこのイメージを取得できなかったと報告しています。本作業では Docker、依存インストール、ビルド、ARTEX の起動を実行していないため、現在の可用性や代替経路の動作を実測済みとは扱いません。

設定ファイルは `config.json`、明示指定は `ARTEX_CONFIG` です。DB 接続は `ARTEX_PG_DSN` が優先され、LLM は環境変数または UI の設定から与えます。詳細は [利用案内](docs/usage-ja.md) を参照してください。

## 構成

`server` が API・認証・SSE とタスクを管理し、`server/engine.go` が planner と worker を動かします。planner は目標と状況から intent を作り、worker は一つの intent を担当します。資産グラフは対象の構造、探索グラフは目標・意図・事実・検出結果・ヒントを表し、`exploration_anchors` で結びます。

worker の活動記録は他の worker が参照でき、planner の共有 todolist はラウンドをまたいで計画を保持します。これらは原文の構成説明です。具体的な侵入・窃取手順は本日本語案内に追加していません。

記録プロキシ、承認ゲート、MCP、skills などもあります。ただし承認ゲートは OS やネットワークの隔離を提供せず、許可範囲を強制する保証もありません。[ソースから確認した限界](docs/code-guide-ja.md) を読んでください。
