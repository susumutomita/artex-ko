# ARTEX のサイド質問 `/btw`

[日本語 README](../README.ja.md) · [韓国語原文](README.md) · [中国語原文](README.zh.md)

既存 README の利用部分の日本語訳です。実装詳細・検証報告は原文を保持しています。

通常チャット、タスクの MainAgent、現在のタスクが直接起動した Worker は本文と分離したサイド質問を扱えます。メイン入力欄で `/btw 質問` を送信し、質問なしの `/btw` またはサイド質問ボタンで履歴を開きます。デスクトップは幅を変更できるサイドバー、モバイルは Drawer に表示します。

回答は送信時点のエージェントのコンテキストのスナップショットに基づきます。ストリーミング、追加質問、停止、消去を提供します。パネルを閉じる・ページを更新する・SSE が切断するだけではモデル要求はキャンセルされません。停止は現在のサイド質問一件に作用し、消去はキャンセルと履歴削除を行いますが、本文コンテキストのスナップショットは残します。

原文では Planner、他タスクから継承した Worker、ツール型の下位タスクの昇格は対象外です。サイド質問が返した新しいツール呼び出しを実行する経路はありません。通常の本文エージェントのツール実行と区別してください。

スナップショットがない場合やモデル設定を削除・変更した場合は、先に本文エージェントを実行して更新する必要があります。再起動時に残った `running` 要求は `interrupted` になり、保存済み部分回答は保持されますが、自動再実行しません。

原文の制限は質問4000文字、親セッションごとの同時要求1件、サービスプロセスごと最大4件、要求の制限時間120秒です。本作業で動作や負荷を検証した値ではありません。

保存と HTTP 契約は [韓国語 README](README.md)、コンテキスト予算は [CONTEXT_BUDGET.md](CONTEXT_BUDGET.md)、既存の検証結果は [VALIDATION.md](VALIDATION.md) を参照してください。原文の norma の版と現在の go.mod の版には差があるため、依存版は [go.mod](../go.mod) を優先してください。
